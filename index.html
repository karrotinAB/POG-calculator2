초도리스트 POG 수집
이 버튼을 즐겨찾기 바로 드래그해서 저장하세요 (최초 1회)
콘솔용 코드 복사
  1. pog.artbox.kr 로그인 → 매장의 매대목록 화면(main.aspx)으로 이동
  2. 저장한 즐겨찾기 클릭 → POG 화면 가운데에 진행률 창이 떠요 (매대 → 상품 상세정보 순서, 매장당 보통 2~5분)
  3. 끝나면 창의 편집기로 보내기 버튼을 누르세요. 안 되면 JSON 저장 후 아래에 끌어다 놓으세요
읽기 전용이에요. POG 사이트에 저장·수정 요청은 보내지 않아요. 매대 하나만 필요하면 매대 화면(md.aspx)에서 눌러도 돼요.
📂 수집 JSON 또는 진행상황 파일을 끌어다 놓거나 클릭

추천 수량 계산 설정

고리 · 진열방식 추가
매대마다 고리 길이가 다르면 여기서 종류를 추가하세요. 예: 스페이스월 고리 120mm, 타공판 고리 200mm. 추가한 종류는 매대 · 선반/고리 · 칸 진열방식 목록에 모두 나와요.
추천 수량 = 진열깊이 ÷ 상품 뎁스 → 팩킹수량 단위로 올림 → 상한 적용 (팩킹수량이 상한보다 크면 팩킹수량이 상한)
직접 바꾼 수량은 설정을 바꿔도 그대로 유지돼요.
